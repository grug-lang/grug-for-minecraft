# The canonical vanilla block names, and each loader's own spelling for the same block.
#
# Mods name vanilla blocks with the canonical name and read them back with get_block, so a name has
# to mean one block on all five loaders. This file says what each loader calls the block a canonical
# name refers to. See #58.
#
# A canonical name is the one modern Minecraft uses, which is the 1.20.6-forge column. Every loader's
# spelling is listed, including the ones that already agree, so this is the whole audit rather than a
# list of patches. The rows cover every block the four older loaders have that has a modern name:
# the Beta block set they share (ids 1-96) and the blocks 1.2.5 added (ids 97-124).
#
# A `-` means the loader has no such block, so a mod naming it gets a host function error there
# rather than a different block. Some blocks have no canonical name and so no row: the flowing
# liquids, and the ones Minecraft dropped or folded into a blockstate (the burning furnace, the
# powered repeater, the locked chest, Beta's April Fools chest, and the lit redstone lamp). The old
# pumpkin is here as `pumpkin` even though it carries a face, which 1.20.6 splits into the blank
# `pumpkin` and `carved_pumpkin`; the row maps the block, not the texture.
#
# The redstone ore, torch and lamp rows follow the modern default state, which is what a placed block
# gets in 1.20.6: a redstone torch is lit, and an ore and a lamp are unlit. The pre-1.13 second names
# are the other state, so `unlit_redstone_torch`, `lit_redstone_ore` and `lit_redstone_lamp` are what
# an old mod wrote for the variant 1.20.6 folds into one block. Naming one on 1.20.6 fails loudly
# instead of giving the other state.
#
# The 1.2.5-forge column is lower cased and word ordered, unlike the others. That game is obfuscated
# at run time, so the loader has no named fields to reflect over and looks its blocks up in a table
# the build dumps from the decompiled dev classes, keyed by a name's words sorted and rejoined (see
# VanillaNames). This column holds those keys, so oreRedstone and redstone_ore are both oreredstone
# here.
#
# Columns, in order: the canonical name, then one per loader under loaders/ in sorted order.
#
# Checked by vanilla_blocks.py, whose --verify-blocks re-checks a column against that loader's own
# block names when given a dump of them and fails on a name neither the column nor
# vanilla_blocks_unmapped.txt mentions, and by vanilla_blocks_test.py and GrugVanillaBlocksTest.
