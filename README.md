# grug for Minecraft

[grug](https://github.com/grug-lang/grug) its primary goal is to serve as a faithful digital preservation format for mods, so that players can continue enjoying the hard work of mod authors for decades to come. If you find a source indicating that a mod should be removed from this repository, please [open a GitHub issue](https://github.com/grug-lang/grug-for-minecraft/issues) with the source.

## Running

```sh
./gradlew runClient
```
