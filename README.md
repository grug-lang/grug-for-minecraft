# grug for Minecraft

> [!NOTE]
> **Mod authors:** grug's primary goal is to serve as a faithful digital preservation format for mods, so that people can continue enjoying the hard work of mod authors for decades to come. We may port mods whose original authors are difficult to contact, particularly older mods at risk of being lost to link rot. If you are an original author or rights holder and want your mod's grug port removed from this repository, please [open a GitHub issue](https://github.com/grug-lang/grug-for-minecraft/issues) and let us know.

This is the [grug](https://github.com/grug-lang/grug) mod loader for Minecraft.

## Running

```sh
./gradlew runClient
```
