# Contributing to grug for Minecraft

grug for Minecraft is built by its maintainers, with LLM help. Overseeing outside pull requests alongside that work is more than the maintainers can take on, so the rules here differ from the organization's default in one way, and the rest of that file still applies.

Bug reports, questions and suggestions are welcome as issues. Discussions are off, so a question is an issue too.

Pull requests are accepted only from the repository's members. GitHub refuses an outside pull request before it is opened, and one that arrives another way is closed without review.

Changes to a bundled mod's pure grug code belong in `grug-lang/grug-for-minecraft-mods` once it exists, where a mod's listed authors can have them merged automatically, as the organization's contributing guidelines describe.

Everything else follows the organization's guidelines: create an issue before a change, and only work on issues labelled `planned`.
