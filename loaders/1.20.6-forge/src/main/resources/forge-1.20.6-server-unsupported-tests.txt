# Tests the 1.20.6 dedicated server cannot run although they define tick_any_side or are
# forwarded_ tests, one path per line. Interim (#167): this mechanism is removed together with
# tick_any_side when #1040 lands.
# Each group below says why its tests cannot run on that server.
#
# The file is named after the loader because this layer sits at the universal jar's root and the
# Fabric-family layers are read from the class path by their bare name: a root
# server-unsupported-tests.txt would shadow theirs in the nested layers.
#
# The click release. The test save's player is in creative, so the inventory screen
# Test.open_inventory opens becomes the CreativeModeInventoryScreen. That client ignores the cursor
# sync (ClientPacketListener.handleContainerSetSlot skips container -1 for it), so the carried item
# the server sets never reaches the overlay, and the overlay takes the hotbar press instead of
# closing the screen. The client-only 1.20.6 run also sets the cursor on the client's open screen,
# so it still proves the release behaviour. This entry goes when the server can set the client's
# cursor on a creative screen, or the fixture opens a screen whose menu takes the sync.
coverage/tests/click_screen_release-Test.grug
#
# The overlay's click and the cursor it deletes. Test.overlay_supported and Test.overlay_drawn
# answer from the joined client (#1099), so the overlay tests do run on this server now, but these
# two still cannot. An overlay's click export runs on that client, so its carried_item read and
# delete_carried_item call touch the client's copy of the cursor while the test sets and reads the
# server's, and no client-to-server cursor write exists yet (#882).
coverage/tests/overlay-Test.grug
jei/tests/jei-Test.grug
#
# The screen-open hook. The test asserts that a screen which has just opened has drawn no frame
# yet, which a joined client cannot promise: it draws frames of its own between the server's open
# and the server's read, so the mark can be set by the time the answer is asked for. The hook it
# proves is the client's own, so the test stays client-only.
coverage/tests/overlay_screen_open-Test.grug
#
# The forced-normalization probe. The state it reads is a client's GL capability, so the runner
# never forces it on a dedicated server and Test.normalization_forced answers false there: on every
# loader but 1.20.6 that fails the assertion that the marked loader forced it, and on 1.20.6 the
# assertion holds without proving the client hooked anything. It stays client-only on every leg now
# that Test.overlay_supported answers from the joined client (#1099).
coverage/tests/hook_forced_normalization-Test.grug
